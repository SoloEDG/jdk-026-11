# 格间

安装：`npm ci`

本地启动：`npm run dev`，访问终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:18260 。

## 彩色数织

- 题库含黑白与彩色两种题目。彩色题的线索按语义色解释：同一种语义色的连续段之间必须隔空，不同语义色可以直接相接。
- 填色工具、行列线索、检查、有限提示（每题 3 次）全部按语义色身份工作；语义色身份不会为了显示方便而合并。
- 旧的黑白存档（version 1）会自动迁移到当前结构继续使用；迁移失败时保留 localStorage 原件，不覆盖。

## 色觉辅助模式

- 最多使用 4 种显示色与 3 种纹样（共 12 个组合）。
- 同一组合不能分配给图中会相接的两种语义色；非相邻语义色可复用同一组合。
- 玩家可以锁定部分语义色的映射；锁定或组合不足造成冲突时，会列出受影响的相接格位供调整。
- 映射草稿在确认前只存在于色觉面板，不会进入解题工具或导出；确认后才用于辅助色视图与 SVG 导出。
- 预览/切换辅助色时可继续解题；展柜可在原色与辅助色之间切换，导出只使用已确认映射，未确认时安全回退原色。

## 测试

- 逻辑测试：`npm test`
- 组件冒烟（jsdom）：`npm run test:ui`
- 类型检查：`npm run typecheck`
